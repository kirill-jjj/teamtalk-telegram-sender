fix: Revert incorrect Scope.TRANSIENT usage in UoW provider

Reverted the previous change that incorrectly added `scope=Scope.TRANSIENT`
to the `get_uow` provider. In Dishka, the transient scope behavior (creating
a new instance on each request) is the default when no explicit scope is
specified.

This fixes the `AttributeError: TRANSIENT` encountered during bot startup.
